# Listing Quality Pre-Flight Checklist — PawPilot Operations SOP

Use this checklist before submitting or updating any Amazon listing. Every item maps to a rule
in our knowledge base and a check in the compliance tooling.

## 1. Title

- [ ] 200 characters or fewer (Pet Supplies category hard limit).
- [ ] Capitalize first letter of each word except short prepositions/conjunctions.
- [ ] No all-caps words.
- [ ] Structure: Brand + Product Type + Key Attribute + Size/Quantity + Color.
- [ ] No promotional phrases (Free Shipping, Hot Sale, Best Seller).
- [ ] No subjective/ranking words (Best, #1, Cheapest, Most Popular).
- [ ] No symbols except hyphen, comma, period, forward slash.
- [ ] No seller contact info, price, or website.

## 2. Bullet Points

- [ ] Five bullets or fewer; each bullet 500 characters or fewer.
- [ ] First bullet leads with primary benefit, not feature.
- [ ] Includes size/dimension bullet for apparel, collars, harnesses, beds.
- [ ] Includes material and care instruction where relevant.
- [ ] No repetition of the full title.
- [ ] Warranty/guarantee only in final bullet, phrased factually.

## 3. Description / A+ Content

- [ ] 2,000 characters or fewer if no A+ Content.
- [ ] No external URLs, seller email, phone, or price.
- [ ] No promotional superlatives.
- [ ] A+ Content includes comparison chart when multiple sizes exist.

## 4. Images

- [ ] Main image: pure white background (RGB 255,255,255).
- [ ] Product fills at least 85% of the main image frame.
- [ ] Longest side 1,000 pixels minimum; 1,600 pixels recommended.
- [ ] No text, logos, watermarks, or inset images on main image.
- [ ] Secondary images include scale reference and lifestyle use.
- [ ] Size chart image included for apparel, harnesses, collars.

## 5. Keywords and Claims

- [ ] Scan title, bullets, description, backend keywords against prohibited list:
  cure, heal, treat, antibacterial, antimicrobial, FDA approved, Best, #1, etc.
- [ ] No competitor brand names or trademarks in backend keywords.
- [ ] Environmental claims qualified per FTC Green Guides.
- [ ] Durability claims substantiated or rephrased (avoid "indestructible").

## 6. Compliance

- [ ] Pet toy: supervision note and small parts warning if applicable.
- [ ] Pet apparel: fiber content and care instructions visible.
- [ ] Harness/collar: maximum weight and girth ranges listed.
- [ ] Electronic pet product: plug type, voltage, certifications (UL/ETL/FCC).

## 7. Final Review

- [ ] Run compliance tool scan and resolve all flagged items.
- [ ] Record reviewer name, date, and any approved exceptions in the change log.
- [ ] Save final copy of title/bullets/description before submission.
