## 三、用户体验走查（模拟真实使用流程）

### 场景：新运营入职第一天

1. **打开页面** → 看到新手引导弹窗，6 步说明清晰 ✅
2. **点击"开始使用"** → 弹窗消失，进入主界面 ✅
3. **侧边栏设置** → 选 deepseek、账号 default、站点 US、模拟数据开 ✅
4. **Tab7 导入数据** → 上传 sales.csv，填账号 test_shop、站点 US → 导入成功 ✅
5. **Tab8 数据管理** → 看到 test_shop 的 3 行数据，SKU 数 2 ✅
6. **侧边栏切账号到 test_shop，关模拟数据** → SKU 列表只剩 TEST-SKU-001/002 ✅
7. **Tab4 运营日报** → 看到 4 个指标卡片、2 个柱状图、SKU 表格（库存预警行标黄/红）、预警列表 ✅
8. **Tab5 销量诊断** → 多选 2 个 SKU → 看到每个 SKU 的指标对比表+柱状图+文字报告 ✅
9. **导出报告** → 下载 MD 文件 ✅
10. **侧边栏历史记录** → 看到刚才的诊断记录，点击回看 ✅
11. **Tab8 删除 test_shop 数据** → 数据清除，SKU 列表变空 ✅

**结论**：完整闭环可用，运营新人能独立完成从导入到分析到导出的全流程。

## 四、发现的问题清单

### 🔴 需要修复的问题

| # | 问题 | 严重度 | 位置 | 说明 |
|---|------|--------|------|------|
| B1 | 政策问答 model 字段不一致 | 🟡 低 | `app/scenarios/policy_qa.py` | 其他场景在顶层返回 `model`/`provider`，政策问答放在 `meta` 里，UI 若统一展示会不一致 |

### 🟡 建议优化的问题

| # | 问题 | 严重度 | 位置 | 说明 |
|---|------|--------|------|------|
| S1 | 日报 sku_rows 为空时无提示 | 🟢 低 | tab4 | 当真实数据日期不覆盖近 7 天时，sku_rows 为空，图表区空白，应显示"暂无数据" |
| S2 | 历史记录无自动刷新 | 🟢 低 | 侧边栏 | 做完分析后历史列表不自动刷新，需手动点刷新按钮 |
| S3 | 自定义属性无法编辑 | 🟢 低 | tab2 | 已添加的自定义属性显示为 disabled，只能删除重建，不能直接编辑 |
| S4 | 预存 flaky 测试 | 🟢 低 | `tests/test_simulated_data.py` | `test_anomaly_cvr_drop` 阈值过紧，CVR 降幅 0.710 略高于 0.70 |

### ✅ 不需要改的（已验证正确）

- 账号数据隔离：simulated OFF 时各账号数据完全隔离 ✅
- 多选 SKU/产品类型：场景层正确循环并合并 ✅
- CSV 导入持久化：account_id/marketplace 正确写入 Postgres ✅
- 模拟数据开关：正确移除无真实数据的模拟 SKU ✅
- LLM Provider 透传：头 → API → 场景 → Generator 全链路 ✅
- 历史记录：保存、列表、回看、导出全链路 ✅
